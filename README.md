
# Arthur Schurhaus - Personal Portfolio

This is the source code for my personal portfolio website, showcasing my projects and experiences as an aspiring web developer.

## Technologies Used

- HTML5
- CSS3 (with Tailwind CSS)
- JavaScript
- Bootstrap 5
- SVG for the background design

## Speacialities
Backend development, TailwindCSS, Server-side operatons, CRUD development. Im studying mainly Flask right now.
## My projects

### 1. Imofácil (Real Estate Management)

**Description:** A fullstack website built using Flask, Tailwind CSS, and SQL for managing real estate listings. Users can easily input and manage crucial property information such as price, size, address, and more. The website is designed to be accessible and user-friendly.

**Key Learnings:** Routing, dynamic endpoints, Flask, templates, CRUD operations, relational databases, server-side operations.

**Live Demo:** [Link to Imofácil project](https://www.linkedin.com/posts/arthurschur_hoje-a-tarde-completei-a-implementa%C3%A7%C3%A3o-da-activity-7224072220925411330-aCFA?utm_source=share&utm_medium=member_desktop)

### 2. Timeless Exhibit

**Description:** A website created to showcase the latest art exhibits from the Art Institute of Chicago. The website displays detailed information about each artwork, leveraging Object-Oriented Programming and API requests to manage the data.

**Key Learnings:** Object-Oriented Programming, API integration, responsive web design.

**Live Demo:** [Timeless Exhibit website](https://timelessexhibit.netlify.app/app/index.html)

### 3. To-Do List App

**Description:** A minimal to-do list application built using Tailwind CSS and JavaScript. The focus was on creating a smooth and responsive user experience.

**Key Learnings:** Tailwind CSS, JavaScript, responsive design.

**Live Demo:** [To-Do List App](https://todo-arthur.netlify.app/app/index.html)

## Getting Started

To run this project locally, follow these steps:

1. Clone the repository:

```
git clone https://github.com/artschur/portfolio.git
```

2. Open the `index.html` file in your preferred web browser.
